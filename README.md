## 这是什么

一套给**室内设计师**用的 Blender 学习程序。

它不假设你有 3D 基础，而是从「你手上正在做的室内项目」出发：用 SketchUp 继续做建模主力，
把 Blender 当作材质、灯光、相机、渲染、动画的**增强工具**，在**不影响当前项目交期**的
前提下把效果图和漫游视频做出来。

可使用 Windows 桌面应用或在线网页。程序**需要联网并登录账号**；学习进度、笔记、收藏和
工作流勾选会同步到个人云端记录，在不同电脑登录同一账号即可继续学习。

## 下载安装

前往 [Releases](../../releases) 下载最新的 `BlenderLearningStudio-Setup-1.3.0.exe`，双击安装。

- 支持 Windows 10 / 11（64 位）
- 自带卸载程序（开始菜单或「设置 → 应用」里均可卸载）
- 需要联网；首次使用请用邮箱注册并完成验证码验证
- 从旧版升级：直接运行新安装包覆盖安装即可，**学习数据会保留**，不用先卸载

> **数据说明**：登录后，学习进度、笔记、收藏和工作流勾选会自动同步到该账号的云端记录；
> 本机同时保留用于界面恢复的缓存。卸载不会删除云端记录。

## 核心特性

### 双学习路线

| 路线 | 周期 | 课时 | 适合谁 |
|------|------|------|--------|
| **Route A** — SU + Blender 工作路线 | 12 周 · 每周 4 课 | 48 | 手上项目在跑，只想快速把效果图做漂亮 |
| **Route B** — Blender 系统成长路线 | 24 周 · 每周 3 课 | 73 | 想完整掌握 Blender，长期投入（主推） |

Route A 的完整工作流：

```
CAD → SketchUp → 空间模型 → Blender → 模型整理 → 材质
    → 灯光 → Camera → 效果图 → 动画 → 漫游视频
```

### 九个栏目（v1.0.0 起「首页」已并入「我的成长」）

| 栏目 | 内容 |
|------|------|
| **我的成长** | 现在该做什么（下一课推荐 / 继续上次）、核心指标、路线进度、连续打卡 |
| **今日学习** | 按天拆解的学习任务清单 |
| **成长路线** | Route A/B 周计划与课时导航 |
| **课时详情** | 教学正文、操作步骤、笔记、学习状态标记 |
| **复习** | 间隔重复复习队列，自动挑出该复习的课时 |
| **快捷键** | 76 条 Blender 快捷键，含 SketchUp 对照与室内用途 |
| **知识实验室** | 材质 / 灯光 / 相机 / 动画 四个速查库 |
| **实际工作模块** | SU → Blender 全流程 5 条工作流，步骤可勾选 |
| **资源库** | 全部内容的统一入口索引 |

### 皮肤靠学分解锁（v1.3.0 起）

界面共有 **11 套皮肤**（字体、圆角、线条、阴影、纹理各不相同），规则是：

- **第一次打开软件，先自己挑 2 套**（弹一次引导，挑满两套才进得去，不给跳过）
- 这两套永久归你、随时互相切换
- **其余 9 套全部锁定**，按学分一套一套解锁：60 / 120 / 180 / 240 / 300 / 360 / 420 / 480 / 540 / 600 / 700
- 自己调颜色的**「色彩调节」是整条路线的最后一项奖励**：730 学分

> 为什么不给默认皮肤：送一套 = 替用户做了第一个审美决定，他只是「接受」；
> 让他自己挑 = 他的第一个动作是「选择」，投入感从第一秒就建立。

### Blender 实操联动（v1.2.0 起）

学分刻意分成两种，界面上**分开显示**，因为它们的含金量不同：

| 来源 | 说明 | 能不能刷 |
|------|------|----------|
| 课程学分 | 来自学习进度（自己点「学完了」） | 能，所以权重低 |
| 实操学分 | 来自 Blender 插件记录的**真实操作** | 刷不了，权重高 |

桌面版可以一键把追踪插件装进 Blender（只连本机 `127.0.0.1`，
不联网、不上传、不改场景），之后在 Blender 里干活，学分自己涨。

### 三语界面

简体中文 / 繁體中文（台灣）/ English。翻译只覆盖界面文案与课程内容 ——
用户自己输入的数据（笔记、收藏标题）原样保留，不做翻译。

| 账号与同步 | WorkBuddy Cloud SDK + 云端行级数据隔离 |

### 架构要点

**账号优先。** 应用启动时先恢复云端登录会话，完成判定前不会错误跳转；未登录只能访问登录页。
登录成功后会先拉取该账号的云端快照，并在学习记录变化后防抖上传。密码验证和保存由云端
认证服务完成，客户端不保存明文密码。

**内容与代码分离。** 全部课程内容放在 `data/*.json`，改内容不用碰代码：

```
data/
├── routes.json          # 路线与阶段定义
├── courses-a.json       # Route A 课时（12 周 × 4 课）
├── courses-b.json       # Route B 课时（24 周 × 3 课）
├── shortcuts.json       # 快捷键库
├── materials.json       # 材质库
├── lighting.json        # 灯光库
├── camera.json          # 相机库
├── animation.json       # 动画课程
├── practice.json        # 练习任务
└── su-to-blender.json   # 工作流
```

**皮肤的"长什么样"和"什么时候给"分开。** 皮肤定义在 `src/lib/skins.ts` 的 `SKINS` 数组，
解锁门槛在同一文件的 `SKIN_UNLOCK_AT` 表里 —— 改外观不该动规则，改规则不该动外观。
门槛表里**每一套都必须有数字**，空着等于免费送。

## 打包成安装程序

前端是标准的 Vite 项目，用 Electron 包一层桌面外壳，再用 NSIS 做安装包。

关键点：

1. **固定端口** — 内置静态服务器必须用固定端口，否则 `origin` 变化会导致 `localStorage` 数据全部丢失
2. **补图标顺序** — 先 `rcedit` 补写 exe 图标，再用 `--prepackaged` 重新封包，否则图标会被覆盖
3. **winCodeSign** — 若打包卡在 `Cannot create symbolic link`，设置 `signAndEditExecutable: false` 跳过签名
4. **发在线版要发构建产物** — 发布目录必须是 `dist`（静态），不能是源码目录；
   产物目录别叫 `dist`（上传工具会排除它），改叫 `public`
